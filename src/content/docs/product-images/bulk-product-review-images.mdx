Paste CSV data into the text field below to generate five-star product review graphics in bulk. Adjust global text sizing if needed, then export all images as a ZIP archive or download/copy them individually.

### CSV Structure Requirements

Your CSV file should be formatted with the following columns:

- **`SKU`** (Column 1): Product item code used for badge display and export filename.
- **`Review Title`** (Column 2): Main headline displayed at the top of the review graphic.
- **`Review Text`** (Column 3): Body copy rendered inside the speech bubble.

> **Note:** Headers are automatically detected. Encapsulate strings containing commas or line breaks in quotation marks (e.g. `"123456","Great item","Smooth, easy process"`).
