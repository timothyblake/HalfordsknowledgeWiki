## Core Experimentation Standards

When building WTO experiments, ensure all scripts follow these technical standards:

### 1. Scoped Namespace & Config Object
Always wrap test logic inside an IIFE and define a clean `Config` object with a unique `testAlias`:

```javascript
(function() {
    const Config = {
        testAlias: 'WTO_1234_FeatureName'
    };
    // Experiment logic...
})();
```

### 2. Defensive DOM Manipulation & Cleanup
- **Remove pre-existing elements**: Never assume an element is rendered only once. Query for and remove previous test elements before injecting new ones.
- **Disconnect observers on route change**: Store `MutationObserver` instances in references and disconnect them when `WTO-route-change` fires.

### 3. Asynchronous Element Detection
Use `MutationObserver` or element detection polling rather than static `setTimeout` calls to guarantee elements are present before modifying the page.
