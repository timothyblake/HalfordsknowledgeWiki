description: Version notes and change history for the Quick Link Tool.

## Version 1.3.5

**17/07/2026**

Added **Remove VRN details**, allowing saved vehicle-registration cookies to be cleared from the current Halfords site in a single click.

## Version 1.3.4

**12/06/2026**

Added support for retrieving the category ID with filters, making the tool compatible with the new headless product-listing pages (PLPs).

## Version 1.3.3

**31/03/2026**

Added an option to get content syntax and fixed issues that prevented **Get Product Syntax** from working correctly.

## Version 1.3.2

**25/03/2026**

Added **Get Content Syntax** as a new feature in the widget.

## Version 1.3.1

**25/03/2026**

Added dynamic domain handling by replacing the hardcoded domain with `window.location.origin`. When searching for a category or product, the widget now stays on the site you are browsing, including `halfords.ie`.

## Version 1.3.0

**20/03/2026**

Added support for `halfords.ie`. The widget now correctly targets `staging.halfords.ie` or `www.halfords.ie` when used on Halfords IE.

## Version 1.2.0

**10/03/2026**

Fixed an issue that prevented the widget from loading on the staging site. Product and category syntax now also work on headless pages.

## Version 1.1.0

**06/03/2026**

Changed the Quick Link Tool to load from a URL, so the bookmark does not need to be saved again when a new version is released.

## Version 1.0.0

**03/03/2026**

Added compatibility for category syntax across headless pages.
